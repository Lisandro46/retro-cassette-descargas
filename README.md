# Retro Cassette · descargas

Reproductor de cassette retro para escuchar tu música local y YouTube Music como en los 80: elegís la cajita, ponés el cassette, apretás PLAY. Con deck y portátil, lados A y B, birome para rebobinar y REC para grabar compilados.

Un proyecto de [TrincherAI](https://trincherai.com/). Acá se publican los instaladores; el código vive en un repositorio aparte.

## Al abrirlo la primera vez

La app no tiene firma digital (cuesta cientos de dólares por año), así que el sistema avisa:

- **Windows:** si aparece «Windows protegió su PC», tocá **Más información → Ejecutar de todas formas**.
- **Mac:** abrí el `.dmg`, arrastrá Retro Cassette a Aplicaciones y la primera vez abrila con **clic derecho → Abrir**. Si macOS no la deja abrir, andá a **Ajustes del Sistema → Privacidad y seguridad → Abrir igual**.

La versión de Mac es nueva y está en prueba: con YouTube Music las agujas de los vúmetros quedan quietas.
